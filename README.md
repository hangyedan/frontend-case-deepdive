# 한계단 문제상황 해결방안 딥다이브 스터디 🪜

> 프론트엔드 개발자 4명이 모여, 실무에서 마주칠 법한 병목 상황을 함께 분석하고
> 각자 해결 방안을 깊이 있게 파고들어 서로에게 나누는 스터디입니다.

## 진행 방식

1. **문제 상황 제시** — 매 회차 한 명이 돌아가며 병목 상황을 만들어 공유합니다.
2. **해결 방안 도출** — AI가 생성해준 해결 방안 체크리스트를 확인하고 검토합니다. 가능한 해결 방안을 최대한 다양하게 펼쳐 봅니다.
3. **개념 선점** — 나온 방안 중 각자 하나씩 골라 딥다이브할 개념을 정합니다.
   이때 **서로 겹치지 않도록** 선택합니다.
4. **딥다이브 & 발표** — 선택한 개념을 각자 파고든 뒤, 라이브 리뷰에서 서로에게
   발표하며 지식을 나눕니다.

## 아카이빙 규칙

이 레포지토리는 딥다이브 내용을 기록으로 남기기 위해 만들었습니다.

- 각 문제 상황마다 폴더가 있습니다. (예: `No1-scroll-interaction`)
- 그 안에 **본인 이름 또는 GitHub 계정명**으로 폴더를 만듭니다.
- 폴더 안에는 딥다이브 내용을 담습니다. 형식은 자유입니다.
  - 정리한 `.md` 파일 업로드
  - 블로그 주소 업로드
  - ...

```
No1-scroll-interaction/
├─ github-account-a/
│  └─ deep-dive.md
├─ github-account-b/
│  └─ README.md (블로그 링크)
└─ ...
```
